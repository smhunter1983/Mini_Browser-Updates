# Mini Browser

**Your minis library, finally under control.**

Every month the studio drops land — Loot Studios, Rescale, Mammoth Factory, Claymore, your MyMiniFactory
creators — as zips of zips holding hundreds of files, each studio naming things its own way. Your slicer is for
slicing. Mini Browser is for everything before that: it turns tens of thousands of Lychee scenes and meshes into
a library you can actually browse, tag and search — without moving, renaming or unpacking a single file.

Built for D&D minis. At home with any 3D-print collection. Used every day on a library of 86,000+ files.

**[⬇ Download for Windows or Mac](https://github.com/smhunter1983/Mini_Browser-Updates/releases/latest)** ·
v1.0.10 · Windows keeps itself up to date

## The Importer — from messy drop to tidy shelf

### Bring it in
- **Drag and drop, or just watch.** Drop files and folders in, or point Mini Browser at your downloads folder:
  it scans it, sub-folders and all, every time it starts, and new drops show up on their own.
- **Zips stay zipped.** It reads straight into archives — zips inside zips too — without extracting anything.
- **PDFs and other clutter are ignored**, and anything you decline to import never comes back to nag you.
  Change your mind? We've got you — it's all waiting in the **Skipped** list, one click from coming back.

### Review before it lands
- **Everything stages first.** New files wait in Import so you can look before they join the library.
  Examine any of them in a full 3D viewer: zoom, rotate.
- **Duplicates skip themselves.** Files you already have, and older releases of minis you already own, are
  marked "Skip Recommended" before you even look.
- **Name it, tag it, pick its cover** right there, for one mini or a whole batch at once.

### Sorted on arrival
- **One mini, one card.** Poses, bust, base, supported and unsupported versions and the Lychee scene come
  together as one model, even when the studio spread them across different zips.
- **Tagged on arrival.** D&D Mode reads species, classes, creature types and sizes straight from the file names,
  and folds spelling variants into one tag (Gyth is Gith).
- **Re-releases handled.** When a studio updates a model, the new version takes over and the old one is hidden,
  flagged so you can clear it out later if you choose.

## The Library — browse, tag, find

### See every mini
- **Lychee scenes show their own preview** — the picture inside every `.lys` file, no grey icons.
- **Meshes get rendered for you** — STL, OBJ (even 400 MB ones) and 3MF become thumbnails in the background
  while you keep working, and any of them opens in a 3D view.
- **Your cover art, your way** — keep the studio's render or pick your own picture for a Model Stack.

### Find anything in a blink
- **Search by words** across names and tags.
- **Filter and sort** by kind, creator, bundle, scale, size, CR and more, with Miniatures, Terrain and Bundles
  tabs and your own shortlists and favorites.
- **Fast on a big library.** Thousands of cards scroll smoothly and search answers as you type.

### Make it yours
- **Your tags are forever.** Tag one file, a whole model or a selection at once; anything you set by hand
  survives every rescan, guaranteed.
- **Fix anything by hand** — merge or split models, link related ones, set kind and category.
- **Nondestructive rename** — give a model the name you want; the files on disk keep theirs.

### Never lose a file
- **Hands off your files.** Mini Browser catalogs them where they are; it never rewrites them.
- **Moves that can't go wrong.** Relocating copies the file, verifies it byte for byte (SHA-256), updates the
  library, and only then sends the original to the Trash.
- **Backups** of the library, with an optional copy to your NAS.
## Download

**[Latest release](https://github.com/smhunter1983/Mini_Browser-Updates/releases/latest)** — pick the file for
your computer:

- **Windows:** `Mini-Browser-Setup-<version>.exe`. It isn't code-signed, so the first time Windows warns you:
  click **More info → Run anyway**. After that it updates itself — a new version downloads in the background,
  then "Restart now / Later".
- **Mac:** `Mini-Browser-<version>-mac.dmg`, drag it to Applications. Unsigned, so the first time right-click the
  app → **Open**. It tells you when a new version is out, with a Download button.

A new install starts with an empty library: point it at your own minis folder.
